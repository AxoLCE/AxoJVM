# AxoJVM
AxoJVM is a WIP Java modloader for MinecraftLCE
> [!IMPORTANT]
> This project is NOT archived or discontinued. Progress stopped because it was announced in the neoLegacy Discord that it will be rewritten, so I was waiting for that update to avoid bugs. However, as of the moment of writing this, it has been almost a month, so I will be back to the development of AxoJVM. After that update releases, there will be an update for Axo that updates it to the rewritten neoLegacy.

## Goals for full release:
- [x] JNI setup
- [x] Runtime with game communication
- [x] Mod detection
- [x] Manifest parsing
- [x] Mod enable/disable
- [x] Side protection (which side can mod run on)
- [x] Blocks registrations
- [x] Items registrations
- [x] Custom Textures
- [x] Custom block drops
- [x] Custom crops
- [x] Block flags (.renderShape, .canWalkThrough)
- [x] Lang files support
- [x] Custom generation rules (custom biomes, block generation etc)
- [ ] Custom armor
- [ ] Custom recipes
- [ ] item "flags" (damage etc.)
- [ ] Basic functions (onBlockDestroy etc.)
- [ ] Mods tab in main menu
- [ ] Installer
### Goals can (and probably will) be updated/changed.
